ARK Proxy Helper

This folder contains the local helper app used for join-code testing and private-server workflow validation.

To test locally:

1. Install Node.js 18+
2. Open a command prompt in this folder
3. Run start-helper.bat
4. Open: http://localhost:8080
5. Use the admin panel at: http://localhost:8080/admin

This helper app is included as a starter local runtime only. It is not a compiled ARK mod binary.
